## Setup

```sh
git clone https://github.com/mono0x/dotfiles ~/.local/share/chezmoi

cd ~/.local/share/chezmoi
./mise bootstrap

killall Dock; killall Finder; killall SystemUIServer
```

## Authenticating with GitHub

Git authenticates to GitHub through [ghtkn](https://github.com/suzuki-shunsuke/ghtkn). A launchd agent runs `ghtkn agent start` at login, and [ghtkn-touchid](https://github.com/yokonao/ghtkn-touchid) unlocks it with a passphrase kept in Keychain behind Touch ID.

The agent starts locked. Unlock it after each login:

```sh
ghtkn-touchid unlock
```

Unlocking also enables refresh tokens, so you only need the device flow once per GitHub App, not every eight hours.

### First-time setup

```sh
# Generate a passphrase, store it in Keychain, and reset the agent with it
ghtkn-touchid reset
# Start the agent again, since the reset stops it
launchctl kickstart "gui/$(id -u)/com.github.suzuki-shunsuke.ghtkn.agent"
ghtkn-touchid unlock
# Get an access token through the device flow
ghtkn auth
```

`ghtkn-touchid reset` deletes the cached tokens, so run `ghtkn auth` again whenever you reset.

### After upgrading ghtkn

The running agent keeps using the old binary. Restart and unlock it:

```sh
launchctl kickstart -k "gui/$(id -u)/com.github.suzuki-shunsuke.ghtkn.agent"
ghtkn-touchid unlock
```

Agent logs go to `~/Library/Logs/ghtkn-agent.log`.

## Updating the mise wrapper

`./mise` is generated by mise. Regenerate it with:

```sh
mise generate install-script -w ./mise
```
