# dotfiles

![CI](https://github.com/mono0x/dotfiles/actions/workflows/ci.yml/badge.svg)

## Setup

```sh
git clone https://github.com/mono0x/dotfiles ~/.local/share/chezmoi

cd ~/.local/share/chezmoi
./mise bootstrap

killall Dock; killall Finder; killall SystemUIServer
```

## Updating the mise wrapper

`./mise` is generated by mise. Regenerate it with:

```sh
mise generate install-script -w ./mise
```
